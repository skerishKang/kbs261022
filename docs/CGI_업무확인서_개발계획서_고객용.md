## 1. 무엇을 만들려고 하나요?

CGI가 지금 가지고 계신 **세 가지**를 하나로 이어 붙이는 일입니다.

<div class="flow">
  <div class="flow-step"><span class="flow-num">1</span><b>CGI 홈페이지</b><span>이미 운영 중<br>개편 업체 연결됨</span></div>
  <div class="flow-arrow">→</div>
  <div class="flow-step"><span class="flow-num">2</span><b>네이버 스마트스토어</b><span>주문·결제가<br>일어나는 곳</span></div>
  <div class="flow-arrow">→</div>
  <div class="flow-step"><span class="flow-num">3</span><b>이카운트 ERP</b><span>이미 사용 중<br>상품·주문·회계 관리</span></div>
  <div class="flow-arrow">→</div>
  <div class="flow-step flow-step-muted"><span class="flow-num">4</span><b>자동화 확대</b><span>배송·회계까지<br>차례로</span></div>
</div>

**새 프로그램을 세 개 만드는 것이 아닙니다.** 홈페이지, 스마트스토어, 이카운트는 이미 있고 이미 쓰고 계십니다. 저희가 하는 일은 **그 사이를 잇는 방법을 만들고, 실제로 어디까지 되는지 먼저 확인하는 것**입니다.

| | 무엇을 쓰나요 | 어떻게 쓰나요 |
|---|---|---|
| **홈페이지** | 이미 있는 홈페이지 + 이미 연결된 개편 업체 | 소개된 상품을 스마트스토어 구매 페이지로 연결합니다 |
| **스마트스토어** | 새로 개설하실 스마트스토어 | CGI가 취급하는 제조사·대리점 상품 정보를 활용해 판매 상품을 등록합니다 |
| **이카운트 ERP** | 이미 쓰고 계신 이카운트 | 상품·주문·회계 업무를 이카운트에서 관리합니다 |

**각 서비스가 이미 제공하는 기능은 먼저 씁니다.** 새로 만드는 것은 연결과 확인에 필요한 최소한뿐입니다.

## 2. 지금 어떤 상황인가요?

| | 현재 상황 | 저희가 파악한 것 |
|---|---|---|
| **홈페이지** | 이미 있고, 개선하고 싶어 하십니다. 개편 업체는 이미 연결되어 있습니다 | 개편 업체가 어디까지 맡는지 아직 정해지지 않았습니다 |
| **스마트스토어** | 새로 개설하실 단계입니다 | 개설·인증을 언제 어디까지 하실지 확인이 필요합니다 |
| **판매할 상품** | CGI가 취급하는 제조사·대리점 제품부터 팔고 싶어 하십니다 | 어떤 제품을 먼저 시작할지 정해지면 바로 움직입니다 |
| **이카운트 ERP** | 이미 사용하고 계십니다 | 상품·주문·회계를 이카운트에서 관리하고 계십니다 |
| **해결하고 싶은 것** | 같은 정보를 두 번 입력하는 일을 줄이고 싶어 하십니다 | 어디가 실제로 중복되는지는 2일 실증에서 함께 확인합니다 |
| **희망 사항** | 주문·배송과 회계 전표 처리 자동화 | 실제 일을 확인하면서 **차례로** 넓혀가겠습니다 |

## 3. 우선 2일 동안 무엇을 확인하나요?

**실제 상품 또는 실제 주문 업무 1건**을 이용해서, 지금 가능한 경로가 어디까지 되는지 확인합니다.

### 3.1 2일 안에 확인하는 것 (필수)

| | 확인할 내용 | 확인 방법 |
|---|---|---|
| **M-1** | **판매할 상품 1건**의 정보가 정리되고, 어디서 온 정보인지 알 수 있음 | 상품 정보표에 출처·가격·옵션·ERP 연결 대상 기재 |
| **M-2** | **홈페이지 → 스마트스토어 구매 경로 1건**이 실제로 눌러서 이동함 | 구매 버튼 실제 클릭 1회로 스토어 상품 페이지까지 이동 확인 |
| **M-3** | **확인한 것과 아직 확인하지 못한 것이 구분된 상태**로 정리됨 | 실행 화면·설정값·남은 문제를 결과물로 제출 |

### 3.2 2일 안에 확인하지 못하는 것 (2단계 — 추가 연동 검증)

| | 확인할 내용 | 필요한 외부 조건 |
|---|---|---|
| **C-02** | 스마트스토어가 **개설 완료** 상태인지 | 사업자 인증·계정 개설 완료 |
| **C-04** | **실제 주문 1건**이 이카운트에 들어오는지 | 스토어 개설 완료 + 실제 결제 + 주문 1건 |
| **C-05** | 그 주문이 **전표로 정확히** 옮겨지는지 | C-04 충족 + 이카운트 계정 권한 |

> **확인하지 못한 것은 "실패"가 아니라 "아직 확인하지 못한 것"으로 보고드립니다.** 왜 확인하지 못했는지와 다음에 어떻게 하면 되는지를 함께 적어 드립니다.

### 3.3 그 다음은

| 단계 | 이름 | 하는 일 | 언제 |
|---|---|---|---|
| **1단계** | **최소 실증** | 위의 **2일 최소 실증** | **우선 진행** |
| **2단계** | **추가 연동 검증** | 스토어 개설·인증, 실제 주문 발생 등 **외부 조건이 갖춰지면 실제 연동 확인** | 조건 충족 시 |
| **3단계** | **상용 구축** | 검증된 결과를 바탕으로 **상품 수 확대, 반복 운영, 주문·배송·회계 자동화** | 범위 결정 후 |

**3단계의 기간과 비용은 지금 말씀드리지 않습니다.** 1·2단계 결과를 보고 함께 정하는 것이 맞습니다.

### 3.4 2일이 안 될 수도 있는 경우

2일은 **우선 작업 기간**입니다. 다만 아래와 같은 사정이 겹치면 시간이 더 걸립니다. **여유 있게 잡아 두실 필요는 없습니다.** 발생하면 그때 다시 말씀드리겠습니다.

| 상황 | 대략적인 추가 소요 |
|---|---|
| 스토어 인증이나 자료 준비가 늦어지는 경우 | 5~7 영업일 (참고) |
| 인증 지연, 자료 재요청, 계정 권한 문제까지 겹치는 경우 | 10~15 영업일 (참고) |

> 위 두 기간은 **기본 일정이 아니라 참고용**입니다. 2일이 우선이며, 추가 소요가 생기면 그때 확정합니다.

## 4. 실증이 끝나면 무엇을 받나요?

| | 받는 것 | 내용 |
|---|---|---|
| **①** | **실행 결과** | 실제로 동작한 화면과 설정값, 캡처 |
| **②** | **연결 가능한 구간** | 홈페이지 → 스토어 → 이카운트 중 어디까지 실제로 이어지는지 |
| **③** | **미해결 문제** | 안 된 구간과 그 사유, 다음에 필요한 조건 |
| **④** | **다음 개발 방향** | 3단계에서 무엇을 먼저 개발할지 결정할 근거 |

> **잘된 것도, 안 된 것도 그대로 보고드립니다.** 1·2단계 결과와 대표님의 우선순위를 함께 보고 3단계 범위를 정합니다.

## 5. 대표님께 확인받을 핵심 사항

아래 두 가지만 알려주시면 됩니다. **답변이 없어도 저희는 사전 준비와 검토를 계속 진행합니다.**

| | 확인할 내용 | 답 |
|---|---|---|
| **1** | **현재 상황과 방향이 맞나요?** — 1장 목표와 2장 상황이 실제와 일치하는지, 다르게 보이면 어떤 부분이 다른지 알려주세요 | ☐ 맞음 &nbsp;&nbsp; ☐ 일부 수정 (내용: ) |
| **2** | **가장 먼저 다룰 상품이나 업무는 무엇인가요?** — 실제 상품 1건은 무엇으로 시작하면 좋을지, 또 3단계 자동화는 주문·배송·회계 중 어느 쪽이 가장 급하신지 | |

### 참고 — 확인 부탁드릴 자료

확인은 편하실 때 주셔도 됩니다. 아래 자료만 준비해 주시면 2일 실증을 바로 시작할 수 있습니다.

| | 필요한 것 | 언제까지 |
|---|---|---|
| 1 | 스마트스토어 개설·인증 진행 상태 | 스토어 단계 착수 전 |
| 2 | 홈페이지 관리 권한, 개편 업체 담당 범위 | 홈페이지 연결 착수 전 |
| 3 | 우선 판매할 제조사 제품 목록 (3~5개 정도) | 상품 정리 착수 전 |
| 4 | 상품 가격·옵션·사진 원본 (1건분) | 상품 정리 진행 중 |
| 5 | 이카운트 ERP 접속 계정과 사용 중인 메뉴 | ERP 확인 착수 전 |
| 6 | 실제 주문 1건을 직접 결제해 볼 수 있는지 | 실제 연동 확인 착수 전 |

> 계정번호·비밀번호·ERP 실제 데이터 같은 민감한 자료는 **공개 저장소에 올리지 않습니다.** 필요한 부분만 화면으로 함께 보거나, 비식별 처리해서 전달 부탁드립니다.
