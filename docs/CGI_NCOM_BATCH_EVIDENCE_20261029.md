### 어려움·실수·원인·해결(지시 §8)
- **카테고리 오분류 재발**: 어휘 매처가 '유튜버 마이크(MV)'를 채소 리프 '마'로, '스피커'를 자동차 스피커 리프로 매핑 — 상위 패밀리 검증 레이어(자동차기기·식품·도서 차단 + 상품명 재분류)를 추가하고 확정 불가분은 제외. 재발 방지는 C16 가드 + 이번 정정 근거로 고정.
- **모델명의 근거 계층**: 페이지 '모델명' 라벨이 1차, 상품명 내 숫자 포함 ASCII 코드가 2차 — 라벨이 있어도 상품명과 혼동되지 않는지 원문 인용으로 기록. 모델 코드가 존재하지 않는 제품군(번들명만 있는 SW)은 81건이 그대로 미등록 — 임의 생성 금지 원칙 유지.
- **공급처와 네이버 요구사항의 차이**: 원산지 복수 표기('중국 또는 멕시코')는 단일 상세코드로 선언 불가 → 04+content(C18). 재고 수량 미공개 상품은 네이버가 수량≥1을 요구 → 하한 1 등록(실재고 아님을 증적으로 구분).
- **API 오류**: E23(중복조회 접두어 히트 오채택) — 원상품 GET 정확 일치 검증(C20)으로 해결, 오채택 장부 행 삭제 후 동일 상품 정상 등록.
- **자동화 한계**: 소비자 화면(네이버 로그인 장벽), 검색색인 지연, ERP 미연동 — 이전 세션과 동일하게 NOT_VERIFIED/별도 분류 유지.
- **차기 배치 재사용**: enrichment(공급처 재조회·모델명 근거 추출) → prep(의미 검증·후보 선정) → register(정확 일치 중복조회·상태머신) 3단 구조와 계약 모듈(C1~C20) — 200·500건 배치에서 추가 개발 없이 재사용.
