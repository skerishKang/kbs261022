# CGI 쇼핑몰 사용자 가이드 (2026-10-25)

## 1. 서비스 개요
CGI 상품 쇼핑몰은 음향·영상·조명 장비를 검색하고 견적/주문할 수 있는 B2B 카탈로그입니다.

## 2. 주요 화면
- 홈: https://skerishkang.github.io/kbs261022/site/index.html
- 전체 상품
- 상품 상세
- 견적 목록 (quote-cart)
- 주문/결제 (checkout)
- 회원가입/로그인
- 마이페이지

## 3. 사용 절차
1. 상품 검색: 상단 검색창에 키워드 입력 후 검색.
2. 상품 상세: 상품 카드 클릭.
3. 견적 목록 담기: 상품 상세에서 "견적 목록에 담기".
4. 견적 요청: 견적 목록에서 "견적 요청" 제출.
5. 주문/결제: 공개 가격 상품만 장바구니에서 주문 생성 후 토스 Sandbox 결제창으로 결제. 테스트 환경에서는 실제 청구되지 않습니다.
6. 회원가입: 이메일·비밀번호로 가입, 이메일 인증 완료 후 로그인.
7. 마이페이지: 주문 내역, 주소, 프로필 관리.

## 4. 주의사항
- 테스트 결제 환경에서는 실제 카드 청구가 발생하지 않습니다.
- 견적 요청 상품은 가격 미확정 상태로, 담당자 확인 후 안내됩니다.
