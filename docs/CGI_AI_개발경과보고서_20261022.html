4. 실제 수행한 개발 과정

  1. 기업 홈페이지 구현 및 모바일 대응 — 기존 CGI 홈페이지 자료(제작 요청서·카다로그·회사소개서)를 근거로 정적 홈페이지 시연본을 구현하고 상품 쇼핑몰 연결을 넣었다. 390px~1920px 반응형과 네이비/그린 로고 자산을 적용했으며, 기존 운영 사이트(cgiinc.kr)는 현재 접속 불가 상태라 대체 시연본으로 제공했다.
  2. 상품 쇼핑몰 개발 — 삼아스토어의 메뉴·검색·목록·정렬·상세 구성을 브라우저로 직접 조사해 그 탐색 방식을 재사용한 CGI 자체 카탈로그를 정적 HTML/CSS/JS로 구현했다. 검색·브랜드/카테고리 필터·정렬·페이지네이션·갤러리·반응형 UI를 포함하며 외부 라이브러리·빌드 스텝이 없다.
  3. 삼아사운드·삼아스토어 데이터 수집 — 기존 분석(PR #6/#12/#13)의 수집기를 재사용해 카테고리 361+532개를 전량 크롤하고 상품 상세 4,575건을 확보했다. 공개 GET만 사용했고 robots Disallow 경로는 방문하지 않았으며, URL 캐시로 재실행 시 네트워크 요청이 0이다.
  4. 4,575건 Excel DB 구축 — 통합상품·공급처원본·옵션SKU·브랜드·카테고리·중복후보·누락·검증현황·향후 네이버·이카운트 매핑 7시트 XLSX와 쇼핑몰용 JSON을 동일 파이프라인에서 생성했다. 미확인 값(공급가·재고·CGI 판매가·네이버 카테고리 ID)은 공란으로 유지했다.
  5. 상품 검색·브랜드 필터·상세페이지 구현 — 상단 검색창, 브랜드/카테고리/공급처 필터(건수 표시), 정렬 4종, 12개 단위 페이지네이션, 대표+추가 이미지 갤러리, 기술 규격·옵션·원본 출처를 포함한 상세페이지를 구현해_shopping몰 규약과 동일한 데이터 계층을 사용했다.
  6. 이미지 누락·혼입 교정 — 수집 원본의 상대 경로 이미지가 로컬 서버 기준 404를 유발하던 문제를 빌더 단계에서 공급처 절대 URL로 정규화했다. 상품 4,575건 전량이 실제 이미지 URL을 확보했고, 깨진 URL 입력 시 대체 문구가 표시되는 동작을 브라우저로 확인했다.
  7. 이카운트 ERP 업무 분석 — 별도 이슈(#20)로 이카운트 ERP 계정·업무 구조와 상품 마스터 필드 간 매핑 경계를 정리하고, 스마트스토어 개설 후 등록 데이터 생성에 필요한 매핑 초안을 준비했다. 실제 ERP 쓰기·주문·결제는 수행하지 않았다.
  8. Cloudflare Pages 배포 및 검증 — 미수행. 배포 도구·배포 기록·접속 검증된 공개 URL이 없으므로 “배포 완료”로 표기하지 않았다. 산출물은 GitHub main 브랜치에 병합되어 저장소에서 직접 확인·다운로드할 수 있다.
