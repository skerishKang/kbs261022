## 오류 사례

### E1 — 원산지 ISO 국가코드 직접 사용 400
- **배치·PR**: 파일럿(배치1) · PR #135
- **실제 오류**: 400 — originAreaCode 거부(ISO DE/US 형식 전송)
- **원인**: 원산지 상세코드는 네이버 자체 코드 체계(020xxxx)이며 ISO 국가코드가 아님
- **해결**: `GET /v1/product-origin-areas` 라이브 조회로 국가명→코드 매칭(독일 0201005·미국 0204000). 이후 이탈리아 0201038·프랑스 0201046 재사용 확정
- **회귀 테스트**: payload 계약 검증(§5 절차 D) — 코드표 외 국가는 라이브 조회 강제
- **위험도**: 저 · **상태**: RESOLVED · **추가 검증**: 불요(코드표 재사용 실측)

### E2 — 택배사 코드 임의 사용 불가
