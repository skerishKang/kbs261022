# CGI 관리자 사용설명서 (2026-10-25)

## 1. 접근 방법
- CGI 회원 로그인 후, 관리자 계정(admin/superadmin)에는 헤더에 "관리자 페이지" 링크가 자동 표시됩니다.
- 링크 클릭 → orders.html (주문 관리) / staff.html (견적 관리).

## 2. 권한 구분
- 일반 회원(member): 마이페이지만 접근.
- 관리자(admin): 주문/견적/환불/ERP 동기화.
- 총관리자(superadmin): 위 + 관리자 지정/해제.

## 3. 주요 기능
- 주문 조회/검색/필터
- 주문 상태 변경 (processing/shipped/delivered 등)
- 결제 취소/환불 (토스 Sandbox)
- ERP 동기화 시도 (테스트 모드)
- 견적 조회/가격 확정/상태 변경
- 관리자 지정/해제 (총관리자만)

## 4. 토스 Sandbox 환불
- 주문 상세에서 환불 금액 입력 후 "환불" 실행.
- 테스트 환경에서는 실제 청구가 발생하지 않습니다.

## 5. 주의사항
- 실제 이메일 인증이 완료된 계정만 총관리자 권한이 활성화됩니다.
- ADMIN_TOKEN은 내부 호환용으로만 유지됩니다.
