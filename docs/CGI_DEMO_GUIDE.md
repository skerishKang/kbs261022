> **(주)시지아이 · CGI Inc** — 방송, 음향의 모든것! 고객을 위한 한 걸음!
> Issue #18 · 검증 기준일 2026-10-22

이 문서는 **회사 홈페이지와 상품 쇼핑몰이 하나로 연결된 통합 시연본**을 대표님께 보여드리는
안내서입니다. 화면 캡처은 `docs/screenshots/integrated-demo/` 에 11종 있습니다.

## 1. 지금 무엇이 만들어져 있나

| | 회사 홈페이지 | 상품 쇼핑몰 |
|---|---|---|
| 경로 | `/website/index.html` | `/site/index.html` |
| 정체 | ㈜시지아이 회사 소개·사업·브랜드·실적·문의 | 수집 공개정보 기반 상품 카탈로그 |
| 메뉴 | ABOUT · BUSINESS · PRODUCTS · REFERENCE · SUPPORT | 홈 · 전체 상품 · 안내 · **회사 홈페이지** |
| 데이터 | 정적 콘텐츠 + 쇼핑몰 데이터 연동 | 공개 수집 샘플 **39건** (브랜드 20종) |

**두 화면은 서로 이동할 수 있습니다.**

- 홈페이지 → 쇼핑몰 : "제품 보기" 링크 5곳 + **브랜드 칩 36개**
- 쇼핑몰 → 홈페이지 : 상단 메뉴 "회사 홈페이지" + 푸터 링크 + **상품 상세 브레드크럼 "← 회사 홈페이지"**

브랜드 칩(예: `SHURE 8`)을 누르면 쇼핑몰이 **해당 브랜드만 필터된 상태**로 열립니다.
이 기능은 3가지 경로로 확인했습니다 — `SHURE` → 8건 표시, `K&M` → 데이터 없음으로 **정상 빈 화면** 표시,
홈페이지 브랜드 칩 36개 전부 실제 클릭 이동 확인.

## 4. 현재 표시 수량에 대한 정확한 안내

- 쇼핑몰에 보이는 **39건**은 공급처 공개 페이지에서 **샘플로 수집한 것**입니다.
- 공급처 카탈로그 **전체 규모는 4,198건**(삼아사운드 2,229 + 삼아스토어 1,969)이며, 이는 **공급처 전체 규모이지 CGI가 판매할 수 있는 수량이 아닙니다.**
- 이슈 #19가 인용한 **4,575건**(2,281+2,294)은 **카테고리 탐색 기준**의 다른 집계이며, 상세 필드 전량 검증을 별도로 진행 중입니다. 두 수치는 **집계 기준이 달라** 나옵니다. 최종 수치는 #19 검증 후 확정해 갱신하겠습니다.
- **가격이 공개되지 않은 상품은 추정하지 않고 "가격 문의"로 표시**합니다.
- 네이버 스마트스토어 개설 전 단계로 **주문·결제 기능은 없습니다.**

## 6. 아직 하지 않은 것 (정직하게)

- **실주소 배포는 하지 않았습니다.** 도메인·호스팅 권한 확인이 필요합니다(→ [배포 안내](CGI_DEPLOYMENT.md)).
- **기존 CGI 운영 홈페이지는 교체하지 않았습니다.** 현재 `https://cgiinc.kr` 이 접속 불가(Cloudflare 521) 상태라 개입하지 않았습니다.
- **주문·결제·장바구니**는 구현하지 않았습니다(스마트스토어 개설 전).
- **ERP 연동**은 이슈 #20/#21 진행 중이며 이 시연본에 포함되지 않았습니다.
