# CGI Online Sales & ERP Integration PoC

A dedicated, time-boxed demonstration of an AI-assisted online sales workflow, developed through visible GitHub issues, independent pull requests, review, and integration.

## Scope
1. Prepare a minimal CGI product catalog and website-to-store purchase path.
2. Investigate and reuse native Naver Smart Store / Ecount ERP integration where supported.
3. Demonstrate one real product data flow, with test evidence and explicitly stated external-account dependencies.
4. Record agent start/end time, human review time, CI results, and actual PoC outcomes.

## Delivery boundary
A two-day proof of concept, not a production-ready store or ERP replacement. No fabricated orders or claims of live integration without evidence.

## Development
- Base branch: main
- Independent feature branches and PRs for separable work
- Do not commit credentials, customer data, internal governance, or recorded calls
- Existing ai-revenue-lab/B71 work is a reference, not proof that this PoC is complete
