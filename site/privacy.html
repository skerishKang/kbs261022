개인정보 수집·이용 안내 (초안)

본 문서는 초안입니다. 개인정보 처리 기준(보유 기간, 처리 위탁 등)은 ㈜시지아이 대표 확정 전까지 미확정이며, 확정 전에는 아래 사실 기반 항목만을 안내합니다.

1. 수집하는 항목 (회원가입 시)

항목필수 여부비고
이메일필수로그인 식별자, 인증·안내 발송
성명필수견적·주문 응대
연락처선택견적·주문 연락
회사/소속선택B2B 견적 응대
비밀번호필수해시로 저장(원문 미저장)

견적 요청·주문 시 입력하는 배송지, 요청 사항 등은 해당 기능 안내에 따라 추가로 수집됩니다.

2. 수집 방법

회원가입 화면, 견적 요청 폼, 주문(체크아웃) 화면, 문의 게시를 통한 직접 입력.

3. 이용 목적

  • 회원 가입·이메일 인증 등 계정 관리
  • 견적 요청 접수 및 담당자 응대
  • 주문 접수, 결제 확인, 배송·설치 안내
  • 서비스 필수 안내(주문 상태, 보안 알림)

4. 보유·저장 위치

회원 정보는 Cloudflare(D1 데이터베이스)에 저장되며, 사이트 자산은 GitHub Pages를 통해 제공됩니다. 동의 이력은 회원 이벤트 기록으로 함께 보관됩니다.

5. 보유 기간 · 제3자 제공 · 처리 위탁

[대표 확정 필요: 보유 기간, 파기 절차, 위탁 서비스 목록] — 확정 전에는 아래 사실만 안내합니다.

  • 회원 탈퇴 시 계정 정보는 비활성화 처리되며, 복구 불가 방식의 삭제 절차는 확정 후 고지됩니다.
  • 결제 기능 이용 시 결제대행사(PG)로 결제 정보가 직접 전달되며, 쇼핑몰은 카드번호 전체를 저장하지 않습니다.

6. 이용자 권리

회원은 언제든 본인 정보 열람·수정(마이페이지)과 회원 탈퇴를 요청할 수 있으며, 문의 시 지체 없이 처리합니다.
