## 2. 초기비용·고정비: 0원 목록과 그 조건

**초기 + 연 고정비가 모두 0원으로 확인되는 곳**: **페이앱**(단 "무료 이벤트", 예고 없이 종료 가능, 약관상 환불 불가), **NICEPAY 베이직**(가입비·연관리비 모두 면제, 단 "프로모션 기간에 한정… 별도 공지 이전까지 유지"), **네이버페이 주문형**(가입비·연관리비 없음 — 수수료 구조가 다름), **포트원**(월 순거래액 5,000만원 미만 이용료 무료 — PG 계약비는 별도).

**0원이 아닌 곳**: 토스페이먼츠 220,000 + 110,000/년 · NICEPAY 프리미엄 550,000(단 연관리비 면제) · KG 이니시스 0~300,000 + 0~300,000(계약형태 의존) · KCP 직접 가입 미확인.

**상시 정책과 프로모션의 구분**은 이 표가 결론입니다:

| 사업자 | 0원의 성격 | 종료 조건(공식 문구) |
| --- | --- | --- |
| 페이앱 | 프로모션 | "무료 이벤트는 **별도 예고없이** 종료될 수 있습니다" |
| NICEPAY | 프로모션 | "면제는 프로모션 기간에 한정되며, **별도 공지 이전까지** 유지" |
| 포트원 | **상시 요금제**(매출 구간) | "월 순거래액 5,000만원 미만 → 이용료 무료" — 종료 문구 없음. 단 **PG 가입비 무료 프로모션은 2024-06-30 종료**(해당 일자 신청까지 적용) |
| 네이버페이 주문형 | 상시(수수료 모델) | 프로모션 아님. 단 **영세·중소 4개월 100% 지원** 같은 이벤트는 별개 |
| 토스페이먼츠 | 없음(청구) | "가입비와 연관리비는 가맹점의 계약형태에 따라 상이할 수 있습니다" → 호스팅·제휴 경로만 가능성 |

**중요**: 포트원의 "0원"은 **포트원 SaaS 요금**이고 PG 계약비는 별개입니다. 1차 보고서(#109)가 기록했듯 포트원 경유라고 PG 가입비가 사라지는 것이 아닙니다. 반면 **PG 계약 없이 자사몰에 붙는 선택지는 페이앱·NICEPAY·KG·KCP뿐**이고, 네이버페이 주문형은 PG 위에 얹히는 **판매 채널**입니다.

## 3. 요율 비교 (VAT 포함 실효, 신규가맹점 관점)

| 사업자 | 카드(공식) | 신규가맹점 처리 | 실효(신규 가정) |
| --- | --- | --- | --- |
| 토스페이먼츠 | 3.4% 별도 | "신규 사업자는 가입 시 '일반' 등급, 상·하반기 국세청 명단 자동 반영·환급" | **3.74%** |
| 페이앱 | 1.9~3.4% 별도 | "카드매출액이 파악되지 않는 신규가맹점은 영중소 환급 미적용" | **3.74%** |
| NICE 베이직 | 3.20% 별도 | 문서에 우대·신규 조항 없음 → 확인 필요 | **3.52%**(미확정) |
| NICE 프리미엄 | 2.90% 별도 | 동일 | **3.19%**(미확정) |
| KG 이니시스 | 3.00~3.50% 별도("호스팅·독립몰 가맹점에 따라 상이") | 미확인 | **3.30~3.85%**(구간) |
| NHN KCP | 직접 가입 요율 미확인 | — | 확정 불가 |
| 네이버페이 주문형 | 카드 일반 3.740% / 영세 1.870% / 중소1 2.530% / 중소2 2.695% / 중소3 2.970% (**VAT 포함 표기**) + **주문관리수수료 0.99% VAT 포함** | "입점일 당일은 등급 무관 '일반' 노출, 다음날부터 해당 등급" | **일반 약 4.73%** (3.740 + 0.99) |

**신규가맹점 요율은 3사가 동일 패턴**입니다: 처음엔 일반(최고) 요율, 국세청 명단 반영 후 자동 인하·환급. 네이버페이는 **입점 다음날**부터 등급 반영이라고 명시합니다. 따라서 "1.9%·1.87%" 류의 홍보 수치는 가입 직후 CGI에 적용되지 않습니다.

**네이버페이 주문형의 함정**: 결제수수료에 더해 **주문관리수수료 0.99%(VAT 포함)**가 붙습니다. 일반 등급 실효 ≈ **4.73%**로 PG 3사보다 1%p 비쌉니다. 이 채널은 "PG 대체"가 아니라 **판매 채널 추가**로 평가해야 맞습니다.

## 4. 정산한도·보증보험 (고가 장비에서 결정적)

| 사업자 | 정산 | 보증보험 |
| --- | --- | --- |
| 토스페이먼츠 | "평균 5일 이내"(업계 평균 15일) | **정산한도 1,000만원까지 면제** |
| NICE 베이직 | 5일 후 | 면제(**최대 정산한도 200만원**) — 초과 시 보험 필요 |
| NICE 프리미엄 | 3일 후 | 면제(**최대 정산한도 1,000만원**) |
| 페이앱 | D+3(실무 "토·일 포함 7일 후") | **건당 50만원 초과 또는 월매출 500만원 초과** 시 요청. 연 15,000~71,500원(서울보증보험, 거래 후 환불 불가), **증권 발행 후 정산** |
| KG 이니시스 | 계약 후 확정 | 요금표에 **보증보험대체비용 34,500 / 51,800 / 86,000 / 172,000 / 344,000원(VAT 포함)** 구간이 명시됨 |
| NHN KCP | 미확인 | 미확인 |
| 네이버페이 주문형 | 네이버 정산 주기(등급·정산 리뉴얼 정책 따름) | 해당 없음(플랫폼 구조) |

CGI 관점 해석: 음향·영상·조명 장비는 **건당 50만원을 흔하게 넘습니다.** 이 조건에서
- **NICE 베이직은 불리**합니다(면제 한도 200만원 → 바로 보험 구간).
- **NICE 프리미엄(한도 1,000만원)과 토스(1,000만원 면제)**가 구조상 맞고,
- **페이앱은 보험 + 정산 후 취소 시 반환금 선입금 + 가상계좌 취소 불가**가 누적됩니다.
- KG는 "대체비용"이 최대 344,000원(VAT 포함)까지 표기되어 있어, 면제 구간이 어디까지인지 확인이 필요합니다.

## 7. 이 문서가 답하지 않는 것 (업체 확인 필요)

1. KG 이니시스·NHN KCP의 **직접 가입(독립몰) 법인 요율과 면제 조건** — 공개 페이지가 계약 협의·호스팅 경로를 전제로 합니다.
2. NICEPAY **신규가맹점에도 3.20%/2.90%가 그대로 적용되는지**, 정산한도 산정 기준(미정산 누적/건당/월).
3. 페이앱 **정산한도 부재**와 무료이벤트 종료 시점.
4. 네이버페이 주문형의 **자사몰 직접 연동 API**(주문관리·장바구니 규약)와 CGI Pages 구조 적합성.
5. 3사 공통: **정산 후 취소 시 수수료 반환 여부**, 업종별(음향·조명 유통) 추가 요율.
6. 포트원 경유 시 **PG 계약 비용의 실제 승계** 여부.

발송용 문안은 [pg-vendor-questions.md](./pg-vendor-questions.md)에 있습니다(발송하지 않음).
