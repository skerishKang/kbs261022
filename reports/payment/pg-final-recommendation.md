# CGI 결제대행사 최종 추천 (2026-10-27)

## 1. 결론

**1순위: NICEPAY 프리미엄. 2순위: NICEPAY 베이직. 3순위: 현행 토스페이먼츠 유지.**

페이앱은 1순위가 아닙니다. 초기·연 고정비가 0원이라는 대표의 최우선 기준은 페이앱이 충족하지만, **동일하게 0원인 NICE 베이직이 카드 요율까지 낮고(3.20% vs 3.4%) 거래조회 API·공식 샌드박스를 갖고, 고가 장비에서 페이앱만 건드리는 보험 트리거(건당 50만원/월 500만원)가 NICE에는 한도 표기 형태로 존재**하기 때문입니다. "무료라도 정산한도·보증보험·안정성 때문에 쓰기 어려운 곳"을 가리라는 지시 기준이 바로 이 지점에서 갈립니다.

| | 1순위 NICE 프리미엄 | 2순위 NICE 베이직 | 3순위 토스(현행) | 페이앱(4순위) |
| --- | --- | --- | --- | --- |
| 초기 / 연 | 550,000 / 0 | **0 / 0** | 330,000 / 110,000 | 0 / 0(이벤트) |
| 실효 카드요율 | **3.19%** | 3.52% | 3.74% | 3.74%(신규) |
| 보증보험 | **1,000만원까지 면제** | 200만원까지 면제 | 1,000만원까지 면제 | **50만원↑/500만원↑ 시 요청**, 증권 후 정산 |
| 정산 | **3일** | 5일 | 평균 5일 이내 | D+3(체감 7일) |
| 상태조회 API | **있음** | 있음 | 있음 | **없음** |
| 무청구 테스트 | **공식 샌드박스(10분)** | 동일 | Sandbox(#71 실증) | **없음(실승인 10분 자동취소)** |
| 환불 | 전액/부분(잔액·부분취소 플래그) | 동일 | 실증 완료 | 부분취소 ○, **가상계좌 취소 불가**, 정산 후 취소는 반환금 선입금 |

월 1,000만원 기준 2년차 총비용: 프리미엄 **3,828,000** < 베이직 4,224,000 < 페이앱 4,488,000(+보험) < 토스 4,598,000. 월 100만원 이하에서는 프리미엄의 550,000원 회수가 느려 베이직이 유리합니다(교차점: 프리미엄 vs 베이직 **월 13,888,889원**).

## 2. 세 가지 판단 기준에 대한 답

**① 가장 경제적인 PG**
- 월매출 1,389만원 이상: **NICE 프리미엄** (가입비 550,000원을 12.6개월에 회수, 이후 매년 토스 대비 약 210만~259만원 절감(월 1,000만~3,000만원 기준)
- 그 이하: **NICE 베이직** (고정비 0 + 요율 3.52%, 페이앱과 같은 고정비에서 요율만 낮음)
- **단, 이 답은 "NICE 신규가맹점에도 표기 요율이 적용된다"는 전제**에 걸려 있습니다. 전제가 깨지면(신규도 일반 3.4%로 시작) 순위는 NICE 0원 고정비 쪽으로 수렴하고, 그때는 **페이앱과 NICE 베이직이 동률**, 그 다음 판단은 기술 항목(조회 API·샌드박스)이 NICE를 이깁니다.

**② 도입 잔여 계약·인증 요건** (NICEPAY 기준)
1. 법인 직접 가입 신청 + 업종·통신판매업 확인(CGI는 Cloudflare Pages 자체 구축이므로 호스팅사 정책이 아니라 독립몰 기준 계약 — KG·토스 공통 문구 "계약형태에 따라 상이")
2. 카드사·정산 심사, 정산계좌 등록
3. **정산한도 확정** — 프리미엄의 1,000만원 기준이 미정산 누적인지 건당인지 월합계인지 문서로 묶어야 함(장비 단가와 직결)
4. 면제 프로모션의 **서면 유효기간** (NICE: "별도 공지 이전까지 유지")
5. 시크릿 발급: 가맹점ID/시크릿키(Basic) 또는 Bearer용 access-token, 클라이언트키(Server 승인 방식), 웹훅 SecretKey → **4종**을 Worker secret으로 등록
6. 웹훅 수신 URL의 https 공개 경로 + `200 / "OK" / text/html` 응답 계약
7. 샌드박스와 운영 키가 다르다는 문서 명시 → 배포 설정 분리

**③ 최소 수정 전환 범위**
- `backend/lib/pg-nicepay.mjs`는 이미 있습니다(PR #113). 부족한 것은 **어댑터 실장**뿐입니다: `pg.mjs`에 `createNicepayPgAdapter()`를 붙이고(`baseUrl`·`fetchFn` 주입은 이미 지원), `worker.js:2120`에서 `env.PG_PROVIDER`로 선택, `:678`·`:973`의 하드코딩 2곳을 어댑터 값으로, `POST /api/payments/nicepay/webhook` 신설, `payments`에 `tid`/`provider 복합키` migration.
- 프런트는 Server 승인 모델(`AUTHNICE.requestPay` + `returnUrl` POST)이므로 **인라인 위젯 두 곳(`cgi-order.js:275-298`, `:387-433`)과 `?toss=success` 처리 분기**가 필요합니다.
- **결제 엔진 신설은 필요 없습니다.** `payments.provider`는 이미 칼럼으로 존재하고 환불 로직은 PG 무관합니다.
- 순차: PR #83(worker.js 소유) 병합 후 착수가 충돌 없이 가능합니다.

## 3. 대표님이 직접 하는 신청 절차 (NICEPAY 우선)

| 순서 | 절차 | 소요·시점 |

| 1 | https://start.nicepay.co.kr 회원가입 → **로그인 직후 "테스트 상점 개설하기"** 클릭 | **당일, 문서상 10분이면 개발 착수** |

| 3 | **이 단계에서 개발자에게 샌드박스 키 인계** → 웹훅 포함 왕복 검증(운영 키와 혼동 금지) | 당일 가능 |

| 5 | **pg-vendor-questions.md의 7문항 발송** → 정산한도·프로모션 유효기간·신규가맹점 요율 회신 수령 | 서면 확보 후 계약 |
| 6 | 정산계좌 등록, 계약서(법인 인감) 제출 | 4·5 완료 후 |
| 7 | 운영 키 발급 → Worker secret 등록 → 전환 시점 결정(개발자 작업) | 대표 승인 시에만 |

**포트원 병행 검토를 원하시면**: 가입 후 데모/테스트 모드로 같은 검증을 할 수 있고 월 순거래액 5천만원 미만 SaaS 요금은 0원이지만, **PG 계약비가 남는다**는 점을 서면으로 먼저 확인해야 합니다(무료 프로모션은 2024-06-30 종료).

**네이버페이 주문형은 PG 대체로 추천하지 않습니다**: 일반 등급 실효 ≈4.73%(결제 3.740% + 주문관리 0.99%)로 3사보다 비싸고, PG가 아니라 판매 채널이라 기존 주문·재고·ERP 흐름과 이중화됩니다. 필요하면 **마케팅 채널 추가**로 별도 검토하세요.

## 4. 이 추천이 약속하지 않는 것

- NICEPAY의 **신규가맹점 요율 3.20%/2.90% 적용**은 문서로 확인되지 않았습니다 → 시뮬레이션은 전제 계산이며 2순위 판정은 ①번의 전제가 깨져도 NICE 베이직 ≥ 페이앱(요율 같고 고정비 같되 조회·샌드박스 우위)입니다.
- KG 이니시스·NHN KCP는 **개발문서를 확보하지 못해 판정 유보**입니다. 부적합이라는 증거가 아니라 검토 미완입니다. KG의 "보증보험대체비용 34,500~344,000원"은 비용 가능성이 보이는 유일한 신규 데이터이므로, 한 줄 enquiries의 가치가 있습니다.
- 어떤 회사와도 **발송·가입·계약·결제**를 수행하지 않았습니다. 기존 토스 운영 설정·Sandbox·키·코드는 그대로이며 전환은 대표 결정 후입니다.
- 실계약 전 검증 가능한 항목만 코드로 검증했습니다(계약 테스트 33개, 백엔드 529개, 변형 24종 전부 포착). HTTP 왕복은 키 없이는 검증 불가능하며 그렇게 주장하지 않습니다.

2. 대표님: `pg-vendor-questions.md`의 NICEPAY 7문항 발송(정산한도 정의·프로모션 유효기간·신규가맹점 요율 3종이 핵심)
3. 개발자(PR #83 병합 후): `createNicepayPgAdapter()` 실장 + 웹훅 라우트 + migration + sandbox e2e(부분취소는 샌드박스 불가이므로 운영 소액 1건 또는 문서 확인으로 대체)
4. 회신 도착 시: 요율 전제를 확정하고 1·2순위 재확인
5. 전환 승인 시에만: 토스 → NICEPAY 운영 배선, 기존 토스 코드는 삭제하지 않고 라우터로 보존
