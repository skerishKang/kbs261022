# AI 투찰가 분석 엔진 설계 (bid/ANALYSIS_DESIGN.md)

상세 화면의 "AI 투찰가 분석" 카드는 회원 전용(흐림+🔒)이며, 엔진은 데이터가 확보되는 이후 단계에
활성화한다. 계산기 화면은 만들지 않는다. 데이터가 없는 시점에 값을 그려 넣지 않는다 — 회원 전용
항목의 화면 예시 수치는 레이아웃 규격 확인용이고, 실제 서비스에서는 아래 입력 데이터로만 계산한다.

## 1. 입력 데이터

1. **기초금액·낙찰하한율** — 나라장터 공고 상세(회원 전용 수집 항목). 낙찰하한율은 공고문·적격심사
   세부기준의 값이 최종이며, 기준표는 §3의 확인값을 참조용으로만 쓴다.
2. **개찰 결과 사정률 분포** — 오픈데이터 "조달청 나라장터 낙찰정보서비스"(§4)로 발주기관·물품분류별
   사정률 히스토리를 수집한다. 사정률 원본 데이터는 현재 수집본에 없다.
3. **참가업체 수** — 개찰 결과의 투찰(참가) 업체 수.

## 2. 산출 정의

1. **낙찰하한가** = 기초금액 × 낙찰하한율(공고 값 우선, 없으면 같은 발주기관·물품분류 최근 하한율
   중앙값 — 이때 표본 수를 함께 표기)
2. **사정률 분포** = 같은 발주기관 × 같은 물품분류(부족하면 상위 공종으로 확장) 개찰 결과의 사정률
   히스토그램. 구간 5~10개, 최근 2년. 표본 수를 그래프와 함께 표기한다.
3. **추천 투찰 구간** = 사정률 분포의 중위권(25~75백분위)에 대응하는 투찰가 구간. 낙찰 가능성은
   분포 백분위로 환산해 표기하되 확정적 표현("반드시", "100%")은 쓰지 않는다.
4. **예상 경쟁 수** = 해당 발주기관 최근 개찰의 참가업체 수 중앙값(±분산).

> 공고문·적격심사 세부기준이 우선**이다. 서비스 적용 전에는 조달청·행안부 고시 원문과 대조한다.

포함하는 것을 권장한다.

## 4. 데이터 수집 — 조달청 나라장터 낙찰정보서비스 (오픈데이터)

- 카탈로그: https://www.data.go.kr/data/15129397/openapi.do (확인된 endPoint:
  `https://apis.data.go.kr/1230000/as/ScsbidInfoService`, 제공: 조달청 조달데이터관리팀)
- 상세 기능(카탈로그 한국어 명칭, 23개): 낙찰된 목록 현황 물품/공사/용역/외자조회, 개찰결과 물품/공사/
  용역/외자 목록 조회, 예비가격상세 목록 조회, 개찰완료·유찰·재입찰 목록 조회 등
- 수집 대상: **개찰결과 목록**(낙찰업체·낙찰금액), **낙찰된 목록**(사정률·투찰률), 참가(투찰) 업체 수,
  기초금액 공개 값 — 표본·기간은 §2와 같다.
- REST 영문 operation 명은 카탈로그 개별 기능 가이드에서 확정해야 한다(카탈로그 화면에는 한국어
  상세기능만 표시). `tools/procurement/g2b_openapi_collector.py`의 `RESULT_OPERATIONS` 맵에
  후보를 두고 `--dry-run`으로 URL을 확인한 뒤, 키 발급 시 실응답으로 보정한다.
- 저장 형식: `bid/assets/data/result-data.js`(`window.CGI_RESULT_DATA`) — results.html과
  분석 카드가 읽는다. 필드: `no`·`ord`·`base_amount`(기초금액)·`success_rate`(사정률)·
  `low_rate`(낙찰하한율)·`bid_amount`(낙찰금액)·`bidder_count`(참가 수)·`winner`(낙찰업체).
  파일이 없으면 두 화면은 "개찰 후 반영"을 유지한다(지어내지 않음).

## 5. 제약

- 표본이 기준(예: 기관×공종 10건 미만)에 못 미치면 구간 대신 "표본 부족"을 표기한다(지어내지 않음).
- 엔진은 Worker(회원 인증 뒤)에서만 계산하고, 원시 히스토리를 화면에 노출하지 않는다.
- 분석 근거(표본 수·기간·출처)를 화면에 함께 표기한다. 위조·과장 금지.

## 6. 단계

① 화면 골격(4차 — 흐림+🔒) → ② 개찰 결과·사정률 수집(낙찰정보 API 키 발급 후, 본 수집기 §4) →
③ 엔진 구현·회원 공개.
